# 🚀 Proyecto Destacado

# AGR - Sistema Inteligente de Gestión para Restaurantes

AGR es un **prototipo funcional (MVP)** desarrollado como proyecto de ingeniería, diseñado para digitalizar la administración de restaurantes mediante una plataforma web moderna.

El sistema integra una **página web pública** con una **aplicación administrativa**, permitiendo centralizar la operación del negocio desde una sola plataforma.

## Funcionalidades implementadas

✅ Inicio de sesión por roles

✅ Gestión de usuarios

✅ Administración de productos

✅ Gestión de mesas

✅ Unión de mesas

✅ Registro de pedidos

✅ Registro de pagos

✅ Página web pública

✅ Reservas en línea

✅ Domicilios en línea

✅ Sincronización entre página web y panel administrativo

✅ API REST documentada
